# MGL PPC · Production Planning & Control

Section-wise production value and target vs achievement, from the line *Target vs Achievement* sheets (Shaft, Bull, Axle, Ring).

**App:** https://hss39518-cmyk.github.io/MGL/

- Login and data: Firebase project **Linetarck** (Authentication + Firestore)
- Settings: `firebase-config.js`
- Database security rules: `firestore-rules.txt` (paste into Firebase console → Firestore → Rules → Publish)
- Android APK: make it at https://www.pwabuilder.com from the app address above

To update the app, replace `index.html` and commit. Every user, including the APK, gets the update automatically.
